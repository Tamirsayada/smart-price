# מחיר חכם

סורק ברקוד לטלפון שממליץ על מחיר מדף לסופר בנתיבות.

- **אתר:** https://tamirsayada.github.io/smart-price/
- **נתונים:** `scripts/ingest.py` רץ כל יום ב-06:30 דרך GitHub Actions. הוא מוריד קובצי PriceFull ו-PromoFull (מחוק שקיפות המחירים) של הסניפים שמוגדרים ב-`config.json` וכותב אותם ל-`docs/data`.
- **תמחור:** `docs/app.js`. המחיר המומלץ הוא חציון השוק כפול `1 + (1 - ציון/100) × תוספת מקסימלית`.
- **הוספה או שינוי של סניפים:** עורכים את `config.json`. מזהה הסניף הוא המספר השלישי בשם הקובץ: `PriceFull<chain>-<subchain>-<store>-...`.
- **רענון ידני:** Actions ← update-and-deploy ← Run workflow.

## מה כבר ידוע (נלמד בזמן הבנייה)
- שמות הקבצים כוללים מקטע של תת-רשת, למשל `PriceFull7290058140886-001-031-...`. מזהה הסניף הוא המקטע השלישי.
- חצי חינם חוסמת גישה מהענן של GitHub (Cloudflare 403). מויקטורי לא חזרו קבצים. שתיהן לא נכללות.
- בנתיבות יש סניפים של רמי לוי, יוחננוף וקרפור היפר. לשופרסל יש סניפי דיל באופקים ובשדרות.
